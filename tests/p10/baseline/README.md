# Independent Rust G4 baseline

This is a comparison application built directly with locked Rust 1.90.0 and its
standard library. It is not generated by il or used in any il compilation path.
It intentionally starts with only GET `/health` (200, `ok`), a 404 fallback
and 405 handling. It binds loopback, handles one request per connection and closes
the connection after writing a byte-counted response. No Cargo dependencies or
package scripts are used.

From the repository root inside the pinned Linux toolchain container:

```sh
rustc --edition=2021 --test tests/p10/baseline/main.rs -o /tmp/il-g4-baseline-tests
/tmp/il-g4-baseline-tests
rustc --edition=2021 -C opt-level=2 tests/p10/baseline/main.rs -o /tmp/il-g4-baseline
/tmp/il-g4-baseline --port 0 --max-requests 3 --deadline-ms 30000
```

The server prints `{"ready":true,"port":N}` and flushes stdout after binding.
Port zero selects an available ephemeral port. The caller must read readiness,
make exactly the requested number of external TCP requests, then wait for exit.
On test failure terminate and reap this owned process. The overall deadline also
bounds idle waiting; each read/write has a maximum two-second timeout. Unknown
arguments, zero counts, excessive counts and invalid deadlines fail explicitly.

For `add_route`, copy `main.rs` into a fresh trial workspace and replace the
single literal `    // G4_HELLO_ROUTE` with the full bytes of
`hello_route.rs.fragment`. Compile and test that edited source. The route accepts
GET `/hello/{name}`, decodes percent-encoded UTF-8 and returns
`{"message":"Hello, NAME"}` with JSON escaping. Empty/multiple path components
yield 404 and invalid percent encodings or UTF-8 yield 400. These baseline tests
do not claim the full il HTTP conformance matrix.

For `fix_type_error`, replace the single `valid` string from `type_error.json`
with `invalid` in the starting source. Run rustc with `--error-format=json` and
retain its actual nonzero exit and E0308 diagnostic. Repair the return expression
using the inverse replacement, recompile and execute the regression requests.

For `rollback`, retain the health-only starting source and executable, apply and
verify the hello route, then restore the starting source through a new Git commit.
Compile it, verify `/hello/name` again returns 404, and rerun the retained original
executable against `/health`. Preserve the actual source diff and command receipts.

The parent G4 driver measures commands, source changes, diagnostics and monotonic
time for three isolated trials of each task. These fixtures and unit tests alone
are not G4 trial evidence and do not mark P10 verified.
