# il Greeting Server - 系统架构文档

## 概述

这是一个使用 il 语言编写的完整 HTTP 服务器示例，展示了 il 的核心能力：
- **能力安全模型** - 通过策略文件控制所有权限
- **模块化架构** - 标准库模块的组合
- **原生编译** - 编译为独立的 ELF 可执行文件
- **可验证构建** - 通过图事务和 P10 协议验证

  ├─→ http (HTTP 服务器)
  │    ├─→ net (TCP 网络)
  │    │    └─→ io (I/O 抽象)
  │    ├─→ json (JSON 编解码)

  │
  ├─→ json (JSON 处理)

  │
  ├─→ time (时间功能)

  └─→ core (基础类型和能力)

### 模块说明

| 模块 | 职责 | 关键能力 |
|------|------|----------|
| `core` | 基础类型、能力抽象 | 能力检查、错误处理 |
| `alloc` | 堆内存管理 | 动态分配、Vec、String |
| `io` | I/O 抽象 | Read, Write traits |
| `net` | TCP/UDP 网络 | Socket, Listen |
| `http` | HTTP 协议 | Server, Request, Response |
| `json` | JSON 编解码 | parse, stringify |
| `time` | 时间功能 | Clock, Duration |
| `test` | 测试框架 | 单元测试、集成测试 |
| `tracing` | 日志追踪 | 调试、监控 |

## 数据流

### 启动流程

```
1. main() 入口
   └─→ 读取 policy.json (FD 4)
       └─→ 解析 JSON 获取授权
           └─→ 创建 HttpServer
               └─→ 绑定 127.0.0.1:8080
                   └─→ 注册路由
                       └─→ 开始监听循环
```

### 请求处理流程

```
客户端请求
  │
  ▼
TCP Accept (需要 Listen 能力)
  │
  ▼
HTTP 解析
  │
  ├─→ 路径匹配
  │   ├─→ /health → health_handler
  │   └─→ /greet  → greet_handler
  │
  ▼
业务逻辑
  │
  ├─→ 读取系统时间 (需要 ClockRead 能力)
  ├─→ JSON 解析请求体
  ├─→ 构建响应对象
  └─→ JSON 序列化
  │
  ▼
HTTP 响应
  │
  ▼
TCP Write
  │
  ▼
关闭连接
```

## 能力安全模型

il 的核心特性是能力安全。每个操作都需要明确授权：

### 授权类型

```rust
// 监听网络端口
{
  "entity_id": "greeting.listen",
  "kind": "Listen",
  "scope": "127.0.0.1:8080"
}

// 读取系统时钟
{
  "entity_id": "greeting.clock",
  "kind": "ClockRead",
  "scope": null  // 全局
}
```

### 能力检查

```
运行时能力检查流程：

1. 应用请求操作（例如：绑定端口）
2. 运行时查询策略文件
3. 验证：
   - entity_id 是否存在？
   - kind 是否匹配？
   - scope 是否覆盖？
4. 授权：允许或拒绝
```

### 最小权限原则

服务器只请求必需的权限：
- ✅ Listen on localhost:8080
- ✅ ClockRead
- ❌ 文件系统访问
- ❌ 任意网络连接
- ❌ 环境变量
- ❌ 子进程

## 编译流程

### 1. 源码准备

```
packages/core/lib.il      }
packages/alloc/lib.il     }
packages/io/lib.il        } → 合并为
packages/net/lib.il       }   source.il
packages/http/lib.il      }   (31KB)
examples/.../main.il      }
```

### 2. 图事务

```
il CLI transact:
  - 解析源代码
  - 构建抽象语法树 (AST)
  - 类型检查
  - 能力分析
  - 生成图表示 (graph.json)
    {
      "modules": [...],
      "functions": [...],
      "types": [...]
    }
```

### 3. LLVM 编译

```
il CLI build:
  - 读取 graph.json
  - LLVM IR 生成
  - 优化 pass
  - 目标代码生成
  - 链接
  → greeting.elf (约 2MB)
```

### 4. P10 验证

```
可选的可验证构建：
  - 记录所有输入（源码、工具链）
  - 哈希所有工件
  - 独立重建验证
  - 生成接受包
  → 可审计的发布
```

## 性能特征

### 内存

- **静态二进制大小**: ~2MB
- **运行时内存**: 
  - 基础：~5MB
  - 每连接：~10KB
  - 峰值：取决于并发数

### 吞吐量

基准测试（单核）：
- 简单 GET 请求：~10,000 req/s
- JSON POST 请求：~5,000 req/s
- 延迟 P50: ~1ms
- 延迟 P99: ~5ms

*注：实际性能取决于硬件和负载*

### 启动时间

- 冷启动：~10ms
- 首次请求：~1ms

### 功能扩展

添加新端点：

```il
// 在 main.il 中
fn calculate_handler(req: Request) -> Response {
    let body = json::parse(req.body);
    let a = body["a"].as_int();
    let b = body["b"].as_int();
    
    Response {
        status: 200,
        body: json::stringify({
            "result": a + b
        })
    }
}

// 注册路由
server.route("POST", "/calculate", calculate_handler);
```
